# 决策记录

按日期记录决策和理由。方案细节见 `design.md`。推翻某条决策时，新增一条记录并注明替代了哪条，旧记录保留。

| 日期 | 决策 | 理由 |
|---|---|---|
| 2026-10-25 | 全部功能做成外部插件，单独建仓库 | DSH 仓库不接受社区 MR |
| 2026-10-25 | dsh web 和 Desktop 都要支持 | 用户两边都用 |
| 2026-10-26 | UI 放在 Plugins 页的 tab 里 | PoC 证明外部插件能加 tab；不改 DSH 就没有别的入口 |
| 2026-10-27 | 统一用 DSH 安装里的 dsh-mcp-client 连接 MCP 服务（声明为可选 peer 依赖） | 和 DSH 共用工具注册机制，工具名稳定；PoC 已验证 |
| 2026-10-29 | 目录由我们自己精选维护，托管在 GitHub Pages | 由我们把控质量；没有后端也能发布 |
| 2026-10-29 | 一期只支持远程 MCP 连接器 | 不用处理本地进程和依赖安装 |
| 2026-10-29 | 一期挂在 profile 根上，不做按会话开关 | 以后加按会话开关是增量改动（design §10） |
| 2026-10-29 | 一期不做审批 | MCP 工具调用在 DSH 里默认放行，审批要另行设计 |
| 2026-10-29 | 启动时服务不可用，一期由用户手动重新挂载 | 简单；mcp-client 自带的重连只覆盖已建立连接断开的情况 |
| 2026-10-29 | 普通配置放在 `$DSH_HOME/connector-hub/connectors.json`，各 profile 共用；密钥存钥匙串 | 用户连接一次到处可用；`storageDomain` 对外部插件太重 |
| 2026-10-29 | 按 0.2.1-rc.3 实现，CI 同时测 `next` | 用户当前版本是 rc.3；rc.4 已发布，Desktop 会自动更新 |
| 2026-10-29 | 采用 pnpm 工作区和三层测试 | 见 design §11、§12 |
| 2026-10-29 | 包名 `dsh-connector-hub`，不带 scope | 用户决定；npmjs 上可用 |
| 2026-10-29 | 第一批连接器：Notion、Xmind（中国版）、高德、百度 | 用户提供的清单；同时覆盖 OAuth、请求头 Key、查询参数 Key 三种认证方式 |
| 2026-10-29 | 推荐用本地凭据网关注入凭据，而不是刷新后重新挂载（待 M0 验证） | rc.3 的 mcp-client 只接受静态请求头；Xmind token 1 小时过期，重挂会让工具反复消失；还能把 Key 挡在 mcp-client 配置和日志之外 |
| 2026-10-29 | OAuth 客户端每台机器各自动态注册为公共客户端（PKCE） | 目录公开、没有后端，没法分发共享的 secret；符合 RFC 8252 |
| 2026-10-29 | 一期只支持 macOS | 用户决定 |
| 2026-10-30 | 一期不接 Xmind 国际版 | 用户决定 |
| 2026-10-30 | 目录托管在 `Looori/looori.github.io` 的 `dsh-connector-hub/` 目录下；删除原有的 VitePress 示例站；提交用 noreply 邮箱 | 用户决定；目录地址是 `looori.github.io/dsh-connector-hub/...` |
| 2026-10-30 | tab 分「我的」和「发现」两页；授权成功后才添加；加停用开关 | 用户提出界面形态；先授权后添加不会留下半成品连接器；停用是一期里临时去掉某个连接器工具的唯一办法 |
| 2026-10-30 | 一期不支持用户自行添加目录以外的连接器 | 接口只接受目录里的 id，凭据只会发往目录里的地址 |
| 2026-10-30 | 按里程碑串行推进，每步五步节奏，每个里程碑开一个新会话，进度记在 `docs/progress.md` | 避免流程混乱，防止跨会话丢失信息 |
| 2026-11-02 | 改按 0.2.1-rc.5 实现：`engines.dsh` 写 `>=0.2.1-rc.5 <0.3.0`，CI 测 rc.5 和 `next`，查源码用 `dsh-v0.2.1-rc.5` 标签。替代 2026-10-29「按 0.2.1-rc.3 实现」 | 用户的 Desktop 已自动更新到 rc.5，npm 的 `latest` 和 `next` 也都是 rc.5；rc.3 到 rc.5 插件用到的接口都没变（design §3），设计不用改 |
| 2026-11-02 | OAuth 改为所有用户共享公共客户端：Notion 用 CIMD，Xmind 只注册一次公共客户端；支持变端口的服务商直接用随机 loopback 端口，不支持的使用登记固定端口，占用时明确报错。替代 2026-10-29「每台机器各自动态注册」 | 避免每台机器重复注册不可管理的客户端；公共客户端只用 PKCE，不分发 secret；用户 token 仍只存各自机器。M0 实测 Notion 支持 CIMD＋随机端口，Xmind 要求固定回调 |
| 2026-11-03 | 第一批连接器新增腾讯文档；百度地图改用查询参数 `ak`，替代此前请求头 `ak` 的配置 | 用户提供的最新 MCP 配置；高德仍用查询参数 `key`，腾讯文档用 `Authorization` 请求头 |
